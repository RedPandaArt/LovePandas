# LovePandas — список контента для первой версии

> Для художника / поиска ассетов. Связан с [GDD.md](GDD.md).
> Приоритеты: **P1** — без этого не выпускаемся, **P2** — желательно к релизу, **P3** — можно позже.

## Главные решения по контенту

- **Персонажи:** на старте только **красная панда — мужская и женская версия**.
- **Босс:** **один**, «закольцованный» — его можно проходить снова и снова (фармить),
  пока не выйдет обновление с новыми боссами.
- **Главный упор — предметы кастомизации:** шапочки, перчаточки, аксессуары и т.п.
  Это основной контент первой версии и основная причина зарабатывать монеты.

## 1. Персонажи (P1)

| Что | Кол-во |
|---|---|
| Красная панда ♂ | 1 |
| Красная панда ♀ | 1 |

**Важно для художника:**
- Стиль: 2D, мультяшный, милый (cozy).
- **Общий скелет и пропорции у обеих версий** — чтобы **любой предмет одежды подходил обоим**
  без перерисовки. Отличия ♂/♀ — в деталях (ресницы, чёлка/причёска, форма мордочки, цвет щёк),
  а не в силуэте тела.
- Персонаж разбит **по слоям/частям** (голова, уши, тело, лапы, хвост, глаза, рот) —
  под анимацию в Unity 2D Animation или Spine.
- Позже добавятся другие зверьки (енот, котёнок…) — скелет стоит продумать так,
  чтобы новые виды можно было посадить на те же точки крепления одежды.

### Анимации персонажа

| Анимация | Где | Приоритет |
|---|---|---|
| Ожидание (дыхание, моргание, шевеление хвостом) | Главный экран | P1 |
| Радость | Получил монеты / задание выполнено | P1 |
| Благодарность / объятие партнёра | Подтверждение задания | P1 |
| Примерка (покрутиться в обновке) | Гардероб, покупка | P2 |
| Реакция на тап по персонажу | Главный экран | P2 |
| Бой: 3 атаки — «Царапки», «Громкий рык», «Бросок пыли» | Бой с боссом | P1 |
| Бой: «Обнимашка» (лечит партнёра) | Бой с боссом | P1 |
| Бой: получение урона | Бой с боссом | P1 |
| Бой: совместный финальный удар (оба персонажа) | Победа над боссом | P1 |
| Бой: победа / празднование | Экран победы | P1 |
| Грустит / устал (для будущей механики настроения) | — | P3 |

Эмоции на мордочке (для анимаций и иконок): обычная, радость, смущение, удивление, грусть, решительность (бой).

## 2. Предметы кастомизации — главный контент (P1)

### Слоты
Каждый предмет надевается в свой слот. Один предмет на слот.

| Слот | Примеры | Кол-во на старт |
|---|---|---|
| **Голова** | шапочки, кепки, бини, венок из цветов, корона, ушки-заколки, бантик, берет, панамка, шляпа ведьмы | 12 |
| **Лицо** | очки круглые, солнечные очки, сердечки-очки, монокль, румянец-наклейка, маска | 6 |
| **Шея** | шарфик, бант, галстук-бабочка, ожерелье, медальон, бандана | 6 |
| **Тело** | футболка, худи, свитер, комбинезон, платье, жилетка, пижама | 8 |
| **Низ** | шортики, юбочка, штанишки, шорты-комбинезон | 5 |
| **Лапы (перчатки)** | перчаточки, варежки, боксёрские перчатки, браслеты, кольцо | 6 |
| **Хвост** | бантик на хвост, колечки, ленточка, гирлянда-огоньки | 5 |
| **Спина** | рюкзачок, крылышки, плащ, гитара за спиной | 4 |
| **Итого в магазине** | | **~52** |

Плюс **эксклюзивы с босса** — см. раздел 4 (ещё ~8).
**Всего предметов на старт: ~60.**

> Минимум, если ресурсов мало: по 4–5 предметов на слот в 5 основных слотах
> (голова, лицо, шея, лапы, хвост) ≈ **25 предметов**. Остальное докладывать обновлениями.

### Редкость и цены (ориентир, см. баланс в GDD)

| Редкость | Доля предметов | Цена |
|---|---|---|
| Обычный | ~50% | 50–100 |
| Необычный | ~30% | 200–400 |
| Редкий | ~15% | 600–900 |
| Легендарный | ~5% | 1000+ |
| Эксклюзив с босса | — | не продаётся |

### Требования к предметам (для художника)
- **Один спрайт подходит обеим версиям** панды (общий скелет).
- Где нужно — **два слоя**: передний и задний (например, шапка: задняя часть за ушами,
  передняя перед ними; шарф: сзади шеи и спереди).
- Нарисованы в **позе по умолчанию**, привязаны к кости слота (голова, шея, тело, лапы, хвост, спина).
- Предметы на лапы — **парные** (левая и правая).
- Для каждого предмета — **иконка для магазина** (квадрат, прозрачный фон).
- Желательно **наборы/сеты** по темам: «Уютная зима», «Пикник», «Пижамная вечеринка»,
  «Рыцарь», «Свидание» — проще продавать и дополнять обновлениями.

## 4. Босс (P1)

**Один босс, закольцован для фарма: ✅ Ленивец Прокрастинации.**
(Остальные идеи — Дракон Рутины, Гидра Немытой Посуды, Туча Скуки, Кракен Телефона — на будущие обновления.)

### Ленивец Прокрастинации — концепт
- **Образ:** огромный сонный ленивец, висит на ветке или развалился в гамаке/на горе подушек.
  Вокруг — недоделанные дела, чашки, пульт, телефон. Смешной и милый, не страшный.
- **Смысл:** олицетворяет «потом сделаем» — то, с чем пара борется, выполняя задания друг другу.
- **Атаки (для анимаций и текста в бою):**
  - «Зевок» — волна сонливости по обоим;
  - «Ещё 5 минуточек» — прячется под одеяло и немного лечится;
  - «Бросок подушкой» — удар по одному из персонажей.
- **Поражение:** не «умирает», а **просыпается, потягивается и уходит делать дела** —
  дружелюбный финал в духе игры.
- **Трофей в доме:** плюшевый ленивец / его гамак.
- **Эксклюзивный лут (сонная тема, ~8 предметов):** ночной колпак, маска для сна (лицо),
  пижама (тело), пижамные штанишки (низ), тапочки-лапки/перчатки-ленивцы (лапы),
  подушка-рюкзак (спина), листик-бантик на хвост, шарф-одеялко (шея).
- **Уровни:** «Ленивец Прокрастинации ур. 2, 3…» — меняется цвет шерсти/аура и размер
  подушечной горы вокруг, новый арт не нужен.

| Что | Кол-во |
|---|---|
| Босс (арт, по слоям под анимацию) | 1 |
| Анимации: ожидание, атака, получение урона, поражение/отступление | 4 |
| Трофей для локации | 1 |
| Эксклюзивные предметы с босса (в его стиле, в разных слотах) | ~8 |

### Как работает фарм одного босса
- После победы босса **можно вызвать снова** (перезарядка, например раз в день — подобрать на тестах).
- Каждая победа → **золото** + **случайный предмет из эксклюзивного набора** босса
  (пока не собрана вся коллекция — потом только золото).
- Босс **растёт в уровне**: «Ленивец Прокрастинации ур. 2, 3…» — больше здоровья и урона,
  больше награда. Цвет/аура босса можно менять по уровням (дёшево, без нового арта).
- Счётчик побед в истории пары: «Победили Ленивца Прокрастинации 7 раз».
- С обновлениями добавляются новые боссы — и новые зоны карты.

## Если ищем готовые ассеты
- Готовые наборы персонажей редко совпадут со стилем и не дадут нашу красную панду —
  **персонажей и одежду лучше заказать у художника** (это лицо игры).
- Готовыми можно взять: **UI-наборы** (кнопки, рамки, панели в cozy-стиле), **VFX**, **звуки и музыку**,
  иконки, возможно фоны локаций.
- Где искать: Unity Asset Store, itch.io, художники — ArtStation, Behance, Telegram/VK-сообщества 2D-артистов.
