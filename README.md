# LovePandas 🐼

Приложение-таскер для пар в виде милой игры на Unity (Android).

У каждого партнёра на смартфоне свой мультяшный персонаж. Выполняешь задания партнёра — зарабатываешь монеты,
ставишь задания партнёру — тратишь монеты, на заработанное наряжаешь персонажа.

Подробности — в дизайн-документе: [docs/GDD.md](docs/GDD.md).
